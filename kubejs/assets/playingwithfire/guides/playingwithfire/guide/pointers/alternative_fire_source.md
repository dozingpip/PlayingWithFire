# An Alternative Fire Source

<ItemImage id="create:blaze_burner" />

When you right click a blaze burner with an empty hand (including via deployer), it will set fire in a straight line up 8 blocks away going from the opposite face of your right click.

If it's just heated, it will only go up to 4 blocks, and it will go up to 8 when superheated. Keep in mind it does use more of the burner's fuel to light fires this way.
This can be used to your advantage for spawning other mobs :)
*Note: This is not vanilla Create, it's just a tweak in the pack*
